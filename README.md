# Rayven Borromeo - Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` - website content
- `style.css` - design and responsive layout
- `script.js` - mobile navigation and footer year
- `profile.jpg` - add your own profile photo (optional)

## Before publishing
1. Replace `Averix433` in `index.html` with your GitHub username.
2. Add your profile picture to this folder and name it `profile.jpg`.
3. Open `index.html` and check the details.

## Publish with GitHub Pages
1. Create a GitHub repository named `Averix433.github.io` (replace with your username).
2. Upload the files in this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait a few minutes and open `https://Averix433.github.io`.
